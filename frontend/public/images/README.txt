OPTIONAL HERO PHOTOGRAPH
------------------------
Drop a landscape photo named  hero-city.jpg  into this folder (e.g. smart bins,
a clean city street, recycling facility; ~1920x1080, <300 KB).

The landing hero shows it at 35% opacity beneath the headline, on top of the
built-in gradient + SVG city illustration. If the file is missing, nothing
breaks - the illustration is shown instead.
